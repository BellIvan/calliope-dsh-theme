# Calliope Library Theme

> 一间藏在赛博都市夹缝里的旧书店，为你抵挡外界的代码喧嚣。

这是一个为 **DeepSeek Harness (DSH)** 开发的 Web UI 主题。灵感来源于“旧书店、复古纸张与斜射进窗户的黄昏日光”。

## ✨ 特性 (Features)

- **📜 旧书页质感**：全局注入深胡桃木底色，并用 SVG 噪点生成纸张纤维纹理。
- **☀️ 丁达尔光束**：通过纯 CSS 几何渐变，在右上角投射出斜向的暖色日光。
- **🪶 物理交互式浮尘**：
  - 使用 Canvas 渲染了 90 颗缓速漂浮的金色尘埃。
  - **光照联动**：尘埃飘进光束时会变亮、变大，离开后恢复暗沉。
  - **鼠标风场**：移动鼠标会推开周围的尘埃。
  - **键盘震动**：打字时，屏幕下方的尘埃会受到轻微震荡。
- **✒️ 原生宋体**：全局阅读区和输入框替换为复古宋体（代码块保留等宽字体保护）。
- **🔑 隐藏彩蛋**：在界面任意处按下特定按键，可召唤“隐藏访客登记本”。

## 🛠️ 安装 (Installation)

1. 将本仓库克隆或下载到本地。
2. 打开 DSH 的 **Plugins**（插件）页面。
3. 选择 **Add plugin**（添加插件），并选择本地的 `calliope-dsh-theme` 文件夹。
4. 安装完成后，刷新页面或新开会话即可生效。

## ⌨️ 彩蛋触发方式

在任意界面（无需输入框聚焦），快速用键盘敲击以下字母：

- `c a l l i o p e`
- `m u s e`
- `m i u s i`

（支持全拼或英文，输入法状态不限。按下退格或回车会重置密码串。）
